# Score orientativo · GESTOS LOCALES
Primer minuto para entrega o canción completa para exploración. Los tiempos no ejecutan acciones automáticas.

- Inicio: R, 1 y P. Corriente, energía 40 %.
- Primer crecimiento: mantener Q y mover el cursor para crear giro; soltar.
- Antes de un acento: 2 y A para acumular; cargar Espacio.
- Acento: soltar Espacio, 3 y mantener W para abrir localmente la red.
- Reorganización: 1; pulsar A de nuevo para memoria normal; usar E brevemente para cortar un filamento y observar reconstrucción.
- Nuevo crecimiento: combinar 2 con Q; repetir descarga cuando lo decidas al escuchar.
- Cierre: S para rastros fugaces, último acento manual con Espacio.

Q/W/E son gestos sostenidos; no cambian modo ni energía. A/S persisten hasta repetir la tecla o reiniciar. Ajusta energía con flechas. No se afirma ensayo musical personal validado.
Variantes: alternar Q/T para retorcer en ambos sentidos; mantener G para concentrar antes de Espacio; Z agita y X promueve exploración local. Elegir al escuchar.
